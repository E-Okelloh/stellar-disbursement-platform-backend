# Backend API Endpoints & Roles

Reference for the backend at [E-Okelloh/stellar-disbursement-platform-backend](https://github.com/E-Okelloh/stellar-disbursement-platform-backend)
— **this is the canonical backend repo for this frontend.** (A different fork happens to run
locally on this machine for dev/testing and has diverged in places — e.g. no separate
approve/submit endpoints — so don't confuse the two.)

Generated by reading the route table in `internal/serve/serve.go` end to end and cross-checking
every handler for stub/TODO markers. **Every route below has a complete, non-stub implementation**
— no `not implemented` handlers were found; only 3 harmless `// TODO:` comments exist elsewhere in
the codebase (implementation notes, not missing functionality).

## Roles

Defined in `internal/data/roles.go` — 8 roles total:

| Role | String value |
|---|---|
| Owner | `owner` |
| Financial Controller | `financial_controller` |
| Developer | `developer` |
| Business | `business` |
| Initiator | `initiator` |
| Approver | `approver` |
| Uploader | `uploader` |
| Finance Officer | `finance_officer` |

Two helper groups are used throughout the route table:
- **All roles** — all 8 above.
- **Business operation roles** — all roles except `developer`.

`initiator` and `approver` are mutually exclusive on the same user (enforced by
`ValidateRoleMutualExclusivity`).

## Auth (public, no token required)

| Method | Path | Notes |
|---|---|---|
| POST | `/login` | Returns `{token}`, or an MFA-required message if MFA is enabled |
| POST | `/mfa` | Completes MFA, returns `{token}` |
| POST | `/forgot-password` | Triggers reset email (or DRY_RUN log) |
| POST | `/reset-password` | Consumes the reset token |
| GET | `/app-config` | CAPTCHA type/site key, whether CAPTCHA/MFA disabled |
| GET | `/organization/logo` | Public org logo |
| GET | `/r/{code}` | Short-link redirect |
